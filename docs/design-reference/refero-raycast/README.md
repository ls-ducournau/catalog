# Référence de style — Raycast (via refero.design)

Captures compressées (22 Mo → 1,8 Mo) depuis refero.design, montrant le design du site raycast.com. Direction retenue pour l'app de suivi films/séries/documentaires :

- **Fond quasi noir** (#000–#0A0A0A), pas de blanc pur nulle part
- **Typo** sans-serif claire, hiérarchie forte (gros titres blancs, sous-texte gris)
- **Accent signature** : dégradés rouge/cramoisi en formes géométriques anguleuses ("shards"), utilisés avec parcimonie comme séparateurs de section ou halos derrière un élément central
- **Cartes** à coins arrondis, fond dégradé propre à chaque item (s'inspire bien d'une affiche de film dominante en couleur)
- **Modale flottante façon palette de commandes** (fond glassy/légèrement translucide, bordure fine) — modèle direct pour l'écran de duel (deux cartes côte à côte dans une modale sombre)
- **Tags/pills** arrondis pour les catégories (genres de films)
- Beaucoup d'espace négatif, contenu centré en colonne

- `03.jpg`, `05.jpg`, `06.jpg` — sections diverses (cartes, extraits UI)
